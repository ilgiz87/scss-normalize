# Настройка форматирования кода

## 📋 Обзор

Проект настроен для автоматического форматирования HTML, CSS, SCSS и JavaScript файлов в соответствии с установленными стандартами.

## ⚙️ Настройки VS Code

### Установленные расширения
- **Prettier - Code formatter** - для форматирования кода
- **Live Sass Compiler** - для компиляции SCSS
- **HTML CSS Support** - для поддержки HTML/CSS
- **EditorConfig for VS Code** - для единообразного форматирования

### Ключевые настройки

#### HTML форматирование:
- Отступы: 2 пробела
- Максимальная длина строки: 120 символов
- Атрибуты выравниваются по вертикали
- Автоматическое перенос строк для длинных атрибутов

#### CSS форматирование:
- Отступы: 2 пробела
- Точки с запятой в конце правил
- Двойные кавычки для строк

#### SCSS форматирование:
- Отступы: 2 пробела
- Точки с запятой в конце правил
- Одинарные кавычки для строк

#### JavaScript форматирование:
- Отступы: 2 пробела
- Точки с запятой в конце выражений
- Одинарные кавычки для строк

## 🚀 Использование

### Автоматическое форматирование
1. Откройте файл в VS Code
2. Сохраните файл (`Ctrl+S`) - форматирование произойдет автоматически
3. Или используйте `Shift+Alt+F` для ручного форматирования

### Команды терминала
```bash
# Установка зависимостей
npm install

# Форматирование всех файлов
npm run format

# Проверка форматирования без изменений
npm run format:check

# Компиляция SCSS
npm run dev

# Сборка для продакшена
npm run build
```

## 📁 Конфигурационные файлы

### `.vscode/settings.json`
Настройки VS Code для проекта, включая:
- Форматирование при сохранении
- Настройки отступов
- Конфигурация Prettier
- Настройки HTML, CSS, SCSS и JavaScript форматирования

### `.prettierrc`
Конфигурация Prettier с настройками для:
- HTML файлов
- CSS файлов
- SCSS файлов
- JavaScript файлов

### `.editorconfig`
Универсальные настройки форматирования для всех редакторов

### `.prettierignore`
Список файлов и папок, исключенных из форматирования

## 🎯 Поддерживаемые типы файлов

- **HTML** (`.html`) - веб-страницы
- **CSS** (`.css`) - стили
- **SCSS** (`.scss`) - препроцессор CSS
- **JavaScript** (`.js`) - скрипты

## 🔧 Устранение проблем

### Если форматирование не работает:
1. Убедитесь, что установлено расширение Prettier
2. Проверьте, что Prettier выбран как форматтер по умолчанию
3. Перезапустите VS Code
4. Проверьте настройки в `.vscode/settings.json`

### Если нужно изменить стиль:
1. Отредактируйте `.prettierrc`
2. Измените настройки в `.vscode/settings.json`
3. Обновите `.editorconfig` при необходимости

## 📝 Рекомендации

- Всегда сохраняйте файлы для автоматического форматирования
- Используйте `npm run format:check` перед коммитом
- Следуйте установленным стандартам для единообразия кода
- Регулярно обновляйте конфигурационные файлы при изменении требований
